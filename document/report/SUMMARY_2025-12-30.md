## 🔑 Key Components

### 1. Core Loader (tyt.js)
- **Purpose:** ES5 module loader and router
- **Features:** define(), require(), exec(), router(), main()
- **Pattern:** No dependencies, works in any browser

### 2. Entity System
- **Common utilities:** dataLoader, i18n, log, render
- **Task module:** Task loading and rendering
- **Test framework:** Assertions, reporter, test runner

### 3. Doc-Site Project
- **Type:** JSON-driven documentation site
- **Features:** Search, filter, i18n (EN/VI/ZH-TW)
- **Deployment:** GitHub Pages (https://tyttoot.github.io/platform/)

### 4. Automation
- **Makefile:** 20+ commands for dev workflow
- **Scripts:** 22 automation scripts
- **Task management:** CLI with status tracking

### 5. GitHub Integration
- **Repository:** https://github.com/tyttoot/platform
- **Wiki:** 17 documentation pages
- **Pages:** Live doc-site deployment
- **Actions:** i18n validation workflow

## 📝 Notes

### File Naming Convention
- camelCase for JavaScript files
- kebab-case for JSON/markdown files
- Lowercase start, capitalize subsequent words

### ES5 Only
- No ES6+ features (arrow functions, const/let, async/await)
- Compatible with older browsers
- No build step required

### Git Strategy
- **staging:** Development branch
- **main:** Production (not used yet)
- Local-only: logs, rules, tasks, tmp, checklists
